# from_scratch/linear_regression — NumPy 线性回归

**交付周**：第 4 周（阶段 1 经典 ML 最小闭环）

## 要解决的问题

用 NumPy 从零实现线性回归的**完整闭环**，并用解析解（最小二乘）验证梯度下降的结果正确。

## 必须自己回答的问题

- 线性回归的预测值怎么从参数得到？`y_hat = X @ w + b` 中每个量是什么形状？
- 损失函数衡量的是什么？MSE 的量纲和单位是什么？
- 梯度下降的一步更新做了什么？`w -= lr * grad` 里 `grad` 是怎么算出来的？
- 为什么训练集表现好但测试集差可能意味着什么？

## 实现清单

- [ ] `predict(X, w, b)` —— 批量预测，注意 `X` 的形状处理
- [ ] `mse(y_pred, y_true)` —— 损失
- [ ] `gradient(X, y, w, b)` —— 解析梯度
- [ ] `train(...)` —— 梯度下降循环，固定种子
- [ ] `normal_equation(X, y)` —— 最小二乘闭式解（`np.linalg.lstsq`），作为正确性基准
- [ ] 训练/测试集划分与指标计算

## 验证要求

| 检查 | 期望 |
|---|---|
| 手算对照 | 小输入下 `y_hat` 与手算结果逐位一致 |
| 闭式解对照 | 梯度下降收敛后与 `lstsq` 解的差异 < 1e-3 |
| 梯度检查 | 有限差分相对误差 < 1e-5 |
| 学习率敏感性 | 学习率过大时 loss 发散并记录现象 |
| 过拟合演示 | 特征数 >> 样本数时训练/测试差距明显 |

## 常见错误

- 特征矩阵少加一列常数 1，导致 `b` 无法学习
- 用 `sum` 而不是 `mean`，学习率需要相应调整却没调
- 梯度公式里 `X.T` 和 `X` 搞反
- 用 `lstsq` 的结果当「我的实现」，实际没实现梯度下降
- 数据没有打乱或没有划分验证集
