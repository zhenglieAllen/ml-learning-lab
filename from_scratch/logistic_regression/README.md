# from_scratch/logistic_regression — NumPy 逻辑回归与 MLP

**交付周**：第 5 周（逻辑回归与多层感知机）

## 要解决的问题

用 NumPy 实现二元分类器：逻辑回归（单层）以及一个最小 MLP（两层），理解激活函数、前向传播与二元交叉熵。

## 必须自己回答的问题

- sigmoid 在概率空间做了什么？它的输出范围和饱和区在哪里？
- 为什么逻辑回归用交叉熵而不是 MSE？
- 交叉熵损失和 sigmoid 组合时，梯度为什么能化简成 `(p - y) * x`？推导出来，不要直接抄。
- 隐藏层引入非线性后，参数量怎么变？每个参数如何影响损失？
- 激活函数有哪些？ReLU 的死区问题是什么？

## 实现清单

- [ ] `sigmoid(z)` / `relu(z)` / `tanh(z)` —— 标注饱和区
- [ ] 逻辑回归：前向、损失、梯度、训练
- [ ] 最小 MLP：两层隐藏层，参数初始化（前向手算一个样本）
- [ ] `train` / `evaluate`（准确率、混淆矩阵）
- [ ] 训练曲线输出

## 验证要求

| 检查 | 期望 |
|---|---|
| 手算前向 | 单样本逐层数值写出并与代码一致 |
| 梯度检查 | 有限差分相对误差 < 1e-5（MLP 也要） |
| 损失单调性 | 学习率合适时训练 loss 整体下降 |
| 初始化对比 | 不同初始化种子下最终结果差异很小 |
| sigmoid 边界 | `z` 很大/很小时不溢出（数值稳定实现） |

## 常见错误

- 交叉熵用 `log` 前忘了 clip，导致 `log(0)`
- 初始化尺度不对（He vs Xavier 没区分），深层网络梯度消失
- softmax 和 sigmoid 混用（多分类用 softmax）
- MLP 的梯度在层间传递时忘记链式法则
