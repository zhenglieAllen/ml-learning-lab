# experiments — 对照与消融实验

一个实验一个子目录。这里放的是**有对照、可复现、有明确问题**的实验，用来验证某个假设。

## 目录结构

```text
experiments/<experiment-name>/
├── README.md       # 完整实验报告（必填）
├── config.yaml     # 配置：超参、种子、数据切分
├── run.sh          # 从干净环境复现的入口
├── logs/           # 训练日志
└── results/        # 结果表、图表
```

## 每个实验必须回答（`LEARNING_PLAN.md` §10）

| 项 | 说明 |
|---|---|
| **问题** | 要验证哪个具体假设？一句话，能被证伪 |
| **基线** | 没有新方法时结果是什么？没有基线的实验没有意义 |
| **变量** | 这次**只**改变什么？其他一律固定 |
| **数据** | 来源、版本、切分方式、潜在泄漏 |
| **环境** | Python、框架、关键依赖、设备 |
| **参数** | 种子、超参、训练步数、批大小 |
| **指标** | 为什么这个指标适合这个问题？ |
| **结果** | 实际数字、日志、图表、失败案例 |
| **结论边界** | 数据够吗？有混杂变量吗？能推广吗？ |
| **复现方式** | 从干净环境运行的具体步骤 |

## 硬性要求

- **不只展示最好的一次结果**。多次运行并报告波动（均值 ± 标准差）。
- **小数据集和玩具例子要明确标记**：只用于验证机制，不足以证明实际效果。
- **保留失败的实验**。它们是知识资产，不要为了让记录好看而删除。
- 图表用代码生成（matplotlib），不要手绘或截图。
