# mistakes — 误解、调试记录与复习卡片

**发现即记录，当天写完**。等一周再补写就失去了价值——那时的记忆已经被修正过了，记下来的会是「我现在知道的东西」而不是「我原来错在哪」。

## 一条记录的格式

每条记录必须包含五要素（`LEARNING_PLAN.md` §11）：

```markdown
## <错误说法 / 错误判断>

- **日期**：YYYY-MM-DD
- **场景**：在哪个主题 / 哪道题上暴露的
- **错误说法**：我原来认为什么
- **正确结论**：实际是什么
- **为什么会错**：具体的认知偏差或缺失前提
- **能区分两者的例子**：一个能判定的具体例子（最好能写成测试）
- **下次如何检测**：遇到什么信号就要警觉
```

「能区分两者的例子」是这条记录最有价值的部分 —— 最好直接变成 `from_scratch/*/tests/` 里的一个测试用例。

## 命名

`NN-slug.md` 或按主题合并到一个文件，用 `---` 分隔条目。**数量少的时候不必拆太细**。

## 复习

每条记录在下列时间点回看：

- 当天结束前
- 约 2 天后（先回答问题再看答案）
- 约 1 周后（不看资料重讲）
- 约 1 个月后（迁移到另一个任务验证）

优先复习：常犯的错、后续主题的前置知识、无法独立推导的公式、只能看懂而不能实现的代码。

已经熟练的部分不要反复抄笔记，改用短测验和实际使用复习。
