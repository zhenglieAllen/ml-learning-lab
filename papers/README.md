# papers — 论文笔记与复现

每篇论文一个子目录，目录名用小写连字符的论文短名：`attention-is-all-you-need`、`bert`、`adam`。

## 目录结构

```text
papers/<paper-name>/
├── README.md        # 论文笔记（模板见 LEARNING_PLAN.md §8）
├── reproduction.md  # 复现实验（可选，做了才建）
├── code/            # 复现代码或对官方仓库的改动
├── results/         # 结果表、日志、图表
└── NOTES.md         # 阅读过程中的疑问与推理
```

## 状态标记

`README.md` 顶部记录阅读状态：`待读` / `初读` / `精读` / `已复现部分结果`

**不要把「已读」当作完成**。一篇论文至少要满足：能说出它解决什么问题、方法的核心假设、实验能支持什么结论、哪些结论实验推不出来。

## 阅读顺序

标题 → 摘要 → 引言 → 图表 → 方法概览 → 关键公式 → 实验设置 → 结果 → 消融 → 局限 → 回读细节

可以调整顺序，但最终必须核对方法和实验细节，**不能只根据摘要形成结论**。

## 论文笔记模板要点

（完整模板见 `LEARNING_PLAN.md` §8）

1. 问题与动机 —— 之前方法有什么限制，论文有证据支持吗
2. 方法 —— 核心思想、流程、关键公式、与已有方法的区别、依赖的假设
3. 实验与证据 —— 数据集、基线、指标、主要结果、消融能支持什么
4. 实现与复现 —— 关键文件、运行命令、与原设置的差异、结果差异
5. 批判性问题 —— 最重要的优势、最重要的局限、我仍然不相信的地方、可以设计的验证实验
6. 结论 —— 能独立解释的内容、尚未验证的猜测、下一步

## 硬性要求

- **区分作者结论与自己的判断**。写清楚哪句是论文说的、哪句是你推的。
- **不要把论文里的单个实验结果当普遍规律**。样本量、数据集、设置都要写出来。
- **关键公式自己写一遍**，不是截图抄。
- 引用具体位置（章节号 / 图表号 / 公式号）。
