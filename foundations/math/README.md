## 必须包含的验证

- **形状检查测试**：至少 5 个，每行都写清 `(batch, features) → ... → (batch, out)`。
- **解析梯度 vs 数值梯度**对照实验（有限差分），误差量级写进笔记。
- 手算示例：数值全部列出，能被逐行核对。

## 常见误解

这一层最容易出现的混淆（详见 `mistakes/`）：

- 行向量 vs 列向量，矩阵乘法的维度约束方向搞反
- 梯度是一个**向量**（所有偏导组成），不是标量
- 梯度指向函数**上升**最快方向，参数更新要减去它
- 学习率过大发散、过小收敛慢，但与「梯度大小」不是一回事
- 有限差分的步长选择影响精度，不是越小越好
