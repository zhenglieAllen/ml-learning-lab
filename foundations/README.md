# foundations — 长期知识沉淀

这里存放**经过验证**的领域知识：能解释、能推导、能举例、知道边界。

区别于 `journal/`（过程记录）和 `from_scratch/`（代码实现）：这里是可长期查阅的参考笔记。

| 子目录 | 内容 | 对应阶段 |
|---|---|---|
| `math/` | 线性代数、微积分、概率统计与优化 | 阶段 1（第 2–3 周） |
| `ml/` | 经典机器学习：训练/验证/测试、损失、过拟合与泛化、评价指标 | 阶段 1（第 4 周） |

## 写作要求

每份笔记包含：

- **推导**：关键公式从哪一步来，每一步依据是什么
- **符号表**：每个符号的含义、形状/维度
- **成立条件与简化假设**：什么时候这套推导会失效
- **最小数值例子**：能手算验证的具体数字
- **边界与反例**：什么时候它不适用
- **链接**：相关 session 记录与 from_scratch 实现

## 命名

`linear-algebra.md`、`calculus-probability.md` 等 kebab-case，与 `LEARNING_PLAN.md` 中的交付物路径一致。
