## 关键概念清单

每个概念都要能回答：它是什么 → 为什么需要 → 怎么用 → 什么时候失效。

- **数据集划分**：三份集各自的用途；为什么测试集只能用一次
- **数据泄漏**：哪些情况算泄漏（标准化用了全部数据、特征里含答案、时间序列打乱）
- **损失函数**：平方损失 vs 交叉熵，分别对应什么分布假设
- **过拟合与欠拟合**：症状、诊断方法（训练/验证曲线）、应对手段
- **基线**：为什么必须先有基线，基线选什么
- **评价指标**：准确率的失效场景；回归看什么；类别不平衡怎么处理
