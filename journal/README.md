# journal — 学习过程记录

存放按时间顺序记录的学习痕迹。这里写的是**过程**，不是结论；结论沉淀到 `foundations/`、`from_scratch/` 等正式目录。

| 子目录 | 内容 | 命名 |
|---|---|---|
| `sessions/` | 单次学习记录（一个主题的一次闭环） | `NN-topic.md`，如 `00-baseline.md`、`01-linear-algebra.md` |
| `weekly/` | 每周复盘 | `YYYY-WW.md`，如 `2026-W44.md` |

## 约定

- **先写后跑**：session 记录的第一节是「学习前：独立思考」，在任何 AI 讲解或代码之前完成。
- **保留错误答案**：答错的、想错的、推翻过的判断全部留着，不要回头美化。
- **预测必须先写**：运行代码前先预测输出，运行时对比「预测 vs 实际」，差异本身就是知识点。
- **session 与周报不重复**：session 记细节和推导，周报记状态变化、阻碍和下一步。

## 模板

- 主题学习记录模板：`LEARNING_PLAN.md` §7
- 每周复盘模板：`LEARNING_PLAN.md` §12
