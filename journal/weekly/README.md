# weekly — 每周复盘

每周固定一次，文件名 `YYYY-WW.md`（ISO 周数），例如 `2026-W44.md`。

## 复盘的目的

不是记录做了什么，而是**依据证据更新状态**。周报是唯一允许修改 `LEARNING_PLAN.md` 阶段状态的地方。

## 写作要点

- 只写**证据**：已提交的代码、已运行的实验、已完成的推导、已通过的测试。
- 阅读时长、AI 生成的内容量**不算**进展证据。
- 只设**一个**下周最重要目标，避免计划过载。
- 阻碍要具体到可行动（"卡在反向传播" 没用，"没想清楚 `zero_grad` 应该在 `backward()` 前还是后" 才有用）。
- 连续卡住时，先缩小问题：构造最小例子、查明错误类型，再决定是补数学还是换资料。

## 模板

见 `LEARNING_PLAN.md` §12，包含：投入时间、计划 vs 实际、本周证据、掌握情况、阻碍、下周计划、更新计划文件的勾选清单。

## 收尾动作

周报最后一项固定动作：回填 `LEARNING_PLAN.md` §13.1 状态表，并给「已通过」主题安排间隔复习（2 天 / 1 周 / 1 个月）。
